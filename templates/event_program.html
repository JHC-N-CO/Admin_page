프로그램 엑셀 업로드

×
CSV/Excel 파일 형식 안내

다음 컬럼을 포함한 CSV 또는 Excel 파일을 업로드하세요:

  • 날짜 (Date): 세션 날짜 (예: 2026. 6. 19 또는 2026-06-19) - 선택사항
  • 세션종류 (Session Type): 세션 종류 (예: Special Interest Group, Parallel Symposium 등)
  • 언어 (Language): 세션 언어 표기 (예: English Session) - 선택사항
  • 세션약어 (Session Abbreviation): 세션 약어 (예: SIG, PS 등) - 선택사항
  • 세션주제 (Session Topic): 세션 제목
  • 발표장소 (Venue): 강의 장소명 (예: Hanra A 또는 Hanra ABC로 여러 장소 통합)
  • 세션시간 (Session Time): HH:MM-HH:MM 형식 (예: 9:00-10:15 또는 09:00-10:15)
  • 좌장 (Chair): 좌장 이름 (여러 명인 경우 "/"로 구분) - 선택사항
    ※ Break, Opening Ceremony, General Assembly 등은 좌장 없이 생성 가능
  • 발표자 (Speaker): 발표자 이름 (여러 명인 경우 "/"로 구분, 예: 김헌민 / 이서영 / 손영민)
    ※ Discussion, Q&A, Break 등 활동은 그대로 입력 (참가자 검색 안 함)
  • 발표 주제 (Lecture Title): 발표 제목 (선택사항)
  • 발표시간 (Lecture Time): HH:MM-HH:MM 형식 (선택사항, 없으면 세션 시간 사용)

※ 같은 세션에 여러 발표자가 있는 경우: (1) "/"로 구분하거나 (2) 세션 정보를 동일하게 여러 행에 입력하세요.

※ 날짜가 없으면 현재 선택된 날짜 탭에 세션이 추가됩니다.

Excel 파일 (.xlsx, .xls) 또는 CSV 파일 (.csv) 업로드 가능합니다.
엑셀 템플릿을 다운로드하여 형식을 확인하세요.
